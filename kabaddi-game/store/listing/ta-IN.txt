== App name ==
கபடி ரெய்டு

== Short description ==
3D கபடி: ரெய்டு, தொடுதல், திரும்புதல். அணியை நடத்தி, கோப்பையை வெல்லுங்கள்.

== Full description ==
கபடி ரெய்டு உங்கள் போனுக்கான 3D கபடி விளையாட்டு. ஒரே மூச்சில் கோட்டைக் கடந்து, ஒரு தடுப்பாளரைத் தொட்டு, பிடிபடும் முன் நடுக்கோட்டைத் தாண்டித் திரும்புங்கள். அல்லது தடுத்து ஆடுங்கள்: ரெய்டைக் கணித்து, ரெய்டரைக் கணுக்கால், தொடை அல்லது இடுப்பில் பிடித்து, சக வீரருடன் சங்கிலி அமையுங்கள்.

விளையாட மூன்று வழிகள்
• விரைவுப் போட்டி: இரண்டு அணிகளையும் ஒரு மைதானத்தையும் தேர்ந்தெடுத்து விளையாடுங்கள்.
• லீக் சீசன்: ஒரு அணியின் உரிமையாளராகுங்கள். சிறந்த வீரர்களைத் தக்கவைத்து, ஏலத்தில் வென்று, உங்கள் ஏழு பேரைத் தேர்ந்தெடுத்து, லீக், பிளேஆஃப், இறுதிப் போட்டி வரை அழைத்துச் செல்லுங்கள், சீசன் தோறும், செய்திகள், வாராந்திர விருதுகள், சாதனைகள் மற்றும் புகழ் மண்டபத்துடன்.
• நேஷன்ஸ் கோப்பை: ஒரு நாட்டையும் அதன் பன்னிரண்டு பேர் அணியையும் தேர்ந்தெடுத்து, கேப்டனை நியமித்து, குழுச் சுற்றிலிருந்து இறுதிப் போட்டி வரை செல்லுங்கள்.

உண்மையான கபடி
• கைத் தொடுதல், கால் விரல் தொடுதல், உதை, கோர்த்த கைகளுக்குக் கீழே டுப்கி, பாய்ச்சலுக்கு மேல் லயன் ஜம்ப்.
• கணுக்கால், தொடை, இடுப்புப் பிடிகள், டேஷ் மற்றும் சங்கிலிப் பிடி, உதவிக்கு வரும் சக வீரர்கள்.
• உண்மையான விதிகள்: போனஸ் புள்ளிகள், மீண்டும் களமிறங்குதல், ஆல் அவுட், செய் அல்லது செத்துமடி ரெய்டு, சூப்பர் டேக்கிள், கோல்டன் ரெய்டு, டைம் அவுட், கார்டுகள், ஒவ்வொரு முடிவுக்கும் நடுவரின் சைகைகள்.
• பாட்டின் ஒரே மூச்சில் ரெய்டு செய்யுங்கள், அல்லது 30 வினாடி கடிகாரத்துடன்: உங்கள் விருப்பம்.
• பன்னிரண்டு அணிகள், பன்னிரண்டு நாடுகள், ஐந்து மைதானங்கள், கிராமத்து மண் தரை முதல் விளக்கொளியில் மின்னும் ஸ்டேடியம் வரை.

உங்கள் வழியில் விளையாடுங்கள்
• எட்டு மொழிகள்: English, हिन्दी, मराठी, தமிழ், తెలుగు, ಕನ್ನಡ, বাংলা, ਪੰਜਾਬੀ.
• தொடு கட்டுப்பாடுகள், கட்டைவிரல் வைக்கும் இடத்திலேயே ஸ்டிக், இடக்கை கட்டுப்பாடுகள், நகர்த்தவும் அளவு மாற்றவும் கூடிய பொத்தான்கள், புதியவர் முதல் லெஜண்ட் வரை நான்கு நிலைகள்.
• உங்கள் போனுக்கு ஏற்ற குறைந்த, நடுத்தர அல்லது உயர் கிராஃபிக்ஸ்.
• இணையம் இல்லாமல் விளையாடலாம். விளம்பரங்கள் இல்லை, வாங்குதல்கள் இல்லை, கணக்கு இல்லை, எந்தத் தரவும் சேகரிக்கப்படுவதில்லை.
