== App name ==
ಕಬಡ್ಡಿ ರೇಡ್

== Short description ==
3D ಕಬಡ್ಡಿ: ರೇಡ್ ಮಾಡಿ, ಮುಟ್ಟಿ, ಹಿಂತಿರುಗಿ. ಫ್ರಾಂಚೈಸಿ ನಡೆಸಿ, ನೇಷನ್ಸ್ ಕಪ್ ಗೆಲ್ಲಿ.

== Full description ==
ಕಬಡ್ಡಿ ರೇಡ್ ನಿಮ್ಮ ಫೋನ್‌ಗಾಗಿ 3D ಕಬಡ್ಡಿ ಆಟ. ಒಂದೇ ಉಸಿರಿನಲ್ಲಿ ಬಾಕ್ ಲೈನ್ ದಾಟಿ, ಒಬ್ಬ ಡಿಫೆಂಡರ್‌ನನ್ನು ಮುಟ್ಟಿ, ಹಿಡಿಯಲ್ಪಡುವ ಮೊದಲೇ ಮಧ್ಯರೇಖೆ ದಾಟಿ ಹಿಂತಿರುಗಿ. ಅಥವಾ ಡಿಫೆಂಡ್ ಮಾಡಿ: ರೇಡ್ ಅನ್ನು ಓದಿ, ರೇಡರ್‌ನನ್ನು ಪಾದದ ಕೀಲು, ತೊಡೆ ಅಥವಾ ಸೊಂಟದಲ್ಲಿ ಹಿಡಿದು, ಸಹ ಆಟಗಾರನೊಂದಿಗೆ ಸರಪಳಿ ಕಟ್ಟಿ.

ಆಡಲು ಮೂರು ದಾರಿಗಳು
• ಕ್ವಿಕ್ ಮ್ಯಾಚ್: ಎರಡು ತಂಡಗಳು ಮತ್ತು ಒಂದು ಮೈದಾನ ಆರಿಸಿ, ಆಡಿ.
• ಲೀಗ್ ಸೀಸನ್: ಒಂದು ಫ್ರಾಂಚೈಸಿಯ ಮಾಲೀಕರಾಗಿ. ನಿಮ್ಮ ಅತ್ಯುತ್ತಮ ಆಟಗಾರರನ್ನು ಉಳಿಸಿಕೊಳ್ಳಿ, ಹರಾಜಿನಲ್ಲಿ ಗೆಲ್ಲಿ, ನಿಮ್ಮ ಏಳು ಜನರನ್ನು ಆರಿಸಿ ಮತ್ತು ಅವರನ್ನು ಲೀಗ್, ಪ್ಲೇಆಫ್ ಮತ್ತು ಫೈನಲ್‌ವರೆಗೆ ಕರೆದೊಯ್ಯಿರಿ, ಸೀಸನ್ ನಂತರ ಸೀಸನ್, ಸುದ್ದಿ, ವಾರದ ಪ್ರಶಸ್ತಿಗಳು, ದಾಖಲೆಗಳು ಮತ್ತು ಹಾಲ್ ಆಫ್ ಫೇಮ್ ಜೊತೆಗೆ.
• ನೇಷನ್ಸ್ ಕಪ್: ಒಂದು ದೇಶ ಮತ್ತು ಅದರ ಹನ್ನೆರಡು ಆಟಗಾರರ ತಂಡವನ್ನು ಆರಿಸಿ, ನಾಯಕನನ್ನು ನೇಮಿಸಿ, ಗುಂಪು ಹಂತದಿಂದ ಫೈನಲ್‌ವರೆಗೆ ಸಾಗಿ.

ನಿಜವಾದ ಕಬಡ್ಡಿ
• ಹ್ಯಾಂಡ್ ಟಚ್, ಟೋ ಟಚ್ ಮತ್ತು ಕಿಕ್, ಹೆಣೆದ ಕೈಗಳ ಕೆಳಗಿನಿಂದ ಡುಬ್ಕಿ ಮತ್ತು ಡೈವ್ ಮೇಲಿನಿಂದ ಲಯನ್ ಜಂಪ್.
• ಪಾದದ ಕೀಲು, ತೊಡೆ ಮತ್ತು ಸೊಂಟದ ಹಿಡಿತ, ಡ್ಯಾಶ್ ಮತ್ತು ಚೈನ್ ಟ್ಯಾಕಲ್, ಸಹಾಯಕ್ಕೆ ಬರುವ ಸಹ ಆಟಗಾರರು.
• ನಿಜವಾದ ನಿಯಮಗಳು: ಬೋನಸ್ ಅಂಕಗಳು, ರಿವೈವಲ್, ಆಲ್ ಔಟ್, ಡು ಆರ್ ಡೈ ರೇಡ್, ಸೂಪರ್ ಟ್ಯಾಕಲ್, ಗೋಲ್ಡನ್ ರೇಡ್, ಟೈಮ್ ಔಟ್ ಮತ್ತು ಕಾರ್ಡ್‌ಗಳು, ಪ್ರತಿ ತೀರ್ಮಾನಕ್ಕೂ ರೆಫರಿಯ ಸಂಕೇತಗಳು.
• ಕ್ಯಾಂಟ್‌ನ ಒಂದೇ ಉಸಿರಿನಲ್ಲಿ ರೇಡ್ ಮಾಡಿ, ಅಥವಾ 30 ಸೆಕೆಂಡ್ ಗಡಿಯಾರದೊಂದಿಗೆ: ನಿಮ್ಮ ಆಯ್ಕೆ.
• ಹನ್ನೆರಡು ಫ್ರಾಂಚೈಸಿಗಳು, ಹನ್ನೆರಡು ದೇಶಗಳು ಮತ್ತು ಐದು ಮೈದಾನಗಳು, ಹಳ್ಳಿಯ ಮಣ್ಣಿನಿಂದ ಬೆಳಕಿನಲ್ಲಿ ಮಿಂಚುವ ಸ್ಟೇಡಿಯಂವರೆಗೆ.

ನಿಮ್ಮ ರೀತಿಯಲ್ಲಿ ಆಡಿ
• ಎಂಟು ಭಾಷೆಗಳು: English, हिन्दी, मराठी, தமிழ், తెలుగు, ಕನ್ನಡ, বাংলা ಮತ್ತು ਪੰਜਾਬੀ.
• ಟಚ್ ಕಂಟ್ರೋಲ್ಸ್, ಹೆಬ್ಬೆರಳು ಇಟ್ಟಲ್ಲೇ ಸ್ಟಿಕ್, ಎಡಗೈ ಕಂಟ್ರೋಲ್ಸ್, ಸರಿಸಬಹುದಾದ ಮತ್ತು ಗಾತ್ರ ಬದಲಿಸಬಹುದಾದ ಬಟನ್‌ಗಳು, ಹೊಸಬರಿಂದ ಲೆಜೆಂಡ್‌ವರೆಗೆ ನಾಲ್ಕು ಹಂತಗಳು.
• ನಿಮ್ಮ ಫೋನ್‌ಗೆ ತಕ್ಕಂತೆ ಕಡಿಮೆ, ಮಧ್ಯಮ ಅಥವಾ ಹೆಚ್ಚು ಗ್ರಾಫಿಕ್ಸ್.
• ಆಫ್‌ಲೈನ್‌ನಲ್ಲಿ ಆಡಿ. ಜಾಹೀರಾತುಗಳಿಲ್ಲ, ಖರೀದಿಗಳಿಲ್ಲ, ಖಾತೆ ಇಲ್ಲ ಮತ್ತು ಯಾವುದೇ ಡೇಟಾ ಸಂಗ್ರಹಿಸುವುದಿಲ್ಲ.
