# Facts

| | |
|---|---|
| **Game** | Hurling Heroes |
| **Sport** | Hurling, the Irish field game |
| **Players per side** | 15 (with substitutes: five changes a match) |
| **Game modes** | Throw-in (a single match), the Summer Championship (with the Tier Two Cup), Watch a match |
| **Grounds** | A parish field (at dusk), a county ground (by day, and at night under floodlights), the national stadium |
| **Match length** | 8, 14, 20 or 35 minutes to play (the full 70 minutes of match time at the longest) |
| **Languages** | English, Irish (Gaeilge) |
| **Graphics levels** | Low, Medium, High; an optional HD pack for High (about 114 MB, downloaded in the game) |
| **Offline** | Yes: the game needs no internet (only the optional HD pack download uses it) |
| **Ads, purchases, account** | None |
| **Data collected** | None |
| **Permissions** | Vibration; internet (only for the optional HD pack) |
| **Platform** | Android |
| **Minimum Android** | Android 7.0 (Vulkan where the phone supports it well, OpenGL ES 3.0 otherwise) |
| **APK size** | About 65 MB (64-bit), about 66 MB (32-bit, for older phones) |
| **Current version** | 0.11.2 (beta) |
| **Engine** | Godot Engine |
| **Developer** | Josh Nason |
| **Contact** | joshnason8@gmail.com |
