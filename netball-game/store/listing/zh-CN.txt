== App name ==
Netball Unleashed

== Short description ==
按真实规则打投球：跑位、传球、0.9 米外防守、在射门圈内投篮。

== Full description ==
Netball Unleashed 是一款手机投球游戏，完全依照现行的投球规则。开中场球、冲向空位、把球传进射门圈后投篮，再用一次拦截把球抢回来。

真实的比赛
• 每队七人，各守自己的区域：GS、GA、WA、C、WD、GD 和 GK，穿上位置背心。
• 中场传球：每次进球后双方轮流开球，必须在中区接住。
• 步法与落地脚、三秒规则、0.9 米阻挡、身体接触、越区、越过一区和短传，全部由两名裁判判罚，每个判决都有手势示意。
• 任意传球、罚球传球、射门圈内的罚传或罚投、界外球和有利原则。
• 四节比赛，节间有真实的休息时间；必须分出胜负时，加时赛打到一方领先两球为止。
• 只有射手（GS）和攻击射手（GA）可以得分，而且必须在射门圈内出手。

随你怎么玩
• 操控全队，或选一件位置背心，整场只打一个位置。
• 快速比赛：23 个投球国家任选两队，从澳大利亚、新西兰、英格兰、牙买加、南非，到马拉维、乌干达、汤加、斐济、新加坡和斯里兰卡。
• 国家杯：两个小组、半决赛、铜牌赛和决赛，积分榜按得分率排名。
• 每场比赛都有数据统计：投篮命中/出手、喂球、中场传球接球、抢断、拦截、篮板和犯规。
• 可开启的联赛规则：Double Zone，每节最后阶段的远距离投篮一球算两球。
• 每节 5、8、10 分钟，或完整的 15 分钟。

三个场地
座无虚席的体育馆、室内球场，以及夜空下的户外球场。

专为手机打造
• 十九种语言：English, Afrikaans, isiZulu, isiXhosa, Sesotho, Setswana, Chichewa, Luganda, chiShona, Kiswahili, Bahasa Melayu, 中文, සිංහල, தமிழ், Cymraeg, Te Reo Māori, Lea Faka-Tonga, Gagana Sāmoa 和 Na Vosa Vakaviti。
• 没有自动代打：传球、投篮、防守，全靠你自己。
• 入门级和中端手机都能流畅运行，还有省电模式。按钮可调整大小和位置，并提供左手布局。
• 支持离线游玩。无广告、无内购、无需账号，不收集任何数据。

Netball Unleashed 是一款独立游戏，与任何投球管理机构、联赛、俱乐部或球员均无隶属关系，也未获得其认可。游戏中的球员均为虚构；国家和规则都是真实的。
