== App name ==
Centre Pass Netball

== Short description ==

== Full description ==
I-Centre Pass Netball yibhola lomnqakiswano efonini yakho, elidlalwa ngokwemithetho yebhola lomnqakiswano njengoba injalo namuhla. Thatha i-centre pass, ugijimele esikhaleni, udlulisele ibhola esiyingini bese uyashaya, bese ulithatha futhi ibhola ngokulihlwitha.

UMDLALO WANGEMPELA
• Abayisikhombisa ohlangothini, ngamunye ezindaweni zakhe: GS, GA, WA, C, WD, GD no-GK, begqoke ama-bib.
• I-centre pass, eshintshana emva kwegoli ngalinye, futhi ebanjwa engxenyeni emaphakathi.
• Ukunyakaza kwezinyawo nonyawo lokwehlela, imizuzwana emithathu, ukuvimba ku-0,9 m, ukuthintana, i-offside, ukweqa ingxenye nephasi emfushane, konke kubizwa onompempe ababili abakhombisa zonke izinqumo.
• Amaphasi amahhala, amaphasi esijeziso, iphasi noma ukushaya kwesijeziso esiyingini, ama-throw-in kanye nenzuzo.
• Amakota amane anamakhefu angempela, nesikhathi esengeziwe kuze kube yilapho iqembu elilodwa lihola ngamagoli amabili, uma umdlalo kufanele ube nowinayo.
• Ngu-Goal Shooter no-Goal Attack kuphela abangashaya igoli, futhi kuphela besesiyingini.

DLALA NGENDLELA YAKHO
• Dlala iqembu lonke, noma ukhethe i-bib udlale isikhundla esisodwa umdlalo wonke.
• Umdlalo osheshayo: noma yimaphi amazwe amabili kwangu-23 adlala ibhola lomnqakiswano, kusukela e-Australia, eNew Zealand, eNgilandi, eJamaica naseNingizimu Afrika kuya eMalawi, e-Uganda, eTonga, eFiji, eSingapore naseSri Lanka.
• Indebe Yezizwe: amaqoqo amabili, ama-semi-final, umdlalo wendondo yethusi kanye nowamanqamu, namatafula ahlelwe ngephesenti lamagoli.
• Izibalo zomdlalo ngamunye: amagoli kumizamo, ama-feed, ama-centre pass amukelwe, ama-gain, ukuhlwitha, ama-rebound nezijeziso.
• Umthetho weligi ongawuvula: i-Double Zone, lapho amagoli ashaywe kude ngasekupheleni kwekota ngayinye abalwa kabili.
• Amakota emizuzu emi-5, 8, 10 noma emi-15 ephelele.
