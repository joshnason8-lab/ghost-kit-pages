Centre Pass Netball

== Short description ==
உண்மையான விதிகளுடன் வலைப்பந்து: பாஸ் செய்யுங்கள், தடுங்கள், கோல் போடுங்கள்!

== Full description ==
Centre Pass Netball என்பது உங்கள் கைபேசிக்கான வலைப்பந்து விளையாட்டு; இன்று நடைமுறையில் உள்ள வலைப்பந்து விதிகளின்படியே விளையாடப்படுகிறது. சென்டர் பாஸை எடுங்கள், காலியான இடத்துக்கு ஓடுங்கள், கோல் வட்டத்துக்குள் பந்தை அனுப்பி ஷூட் செய்யுங்கள், பின்னர் இடைமறித்துப் பந்தை மீண்டும் கைப்பற்றுங்கள்.

உண்மையான ஆட்டம்
• ஒரு அணிக்கு ஏழு பேர், ஒவ்வொருவரும் தத்தம் பகுதிகளில்: GS, GA, WA, C, WD, GD, GK — பிப் அணிந்தபடி.
• சென்டர் பாஸ்: ஒவ்வொரு கோலுக்குப் பிறகும் அணிகள் மாறி மாறி எடுக்கும்; நடு மூன்றில் ஒரு பகுதியில் பிடிக்கப்பட வேண்டும்.
• கால் அசைவும் தரையிறங்கும் காலும், மூன்று வினாடி விதி, 0.9 மீ தடை (obstruction), தொடுதல் (contact), ஆஃப்சைட், ஒரு பகுதியைத் தாண்டும் பாஸ், குறுகிய பாஸ் — இவை அனைத்தையும், ஒவ்வொரு முடிவையும் சைகையால் காட்டும் இரண்டு நடுவர்கள் தீர்மானிக்கிறார்கள்.
• ஃப்ரீ பாஸ், பெனால்டி பாஸ், கோல் வட்டத்துக்குள் பெனால்டி பாஸ் அல்லது ஷாட், த்ரோ-இன், அட்வான்டேஜ்.
• உண்மையான இடைவேளைகளுடன் நான்கு காற்பகுதிகள்; வெற்றியாளர் கட்டாயம் தேவைப்படும் போட்டிகளில், ஒரு அணி இரண்டு கோல் முன்னிலை பெறும் வரை கூடுதல் நேரம்.
• Goal Shooter, Goal Attack ஆகிய இருவர் மட்டுமே கோல் போட முடியும், அதுவும் கோல் வட்டத்துக்குள் இருந்து மட்டுமே.
