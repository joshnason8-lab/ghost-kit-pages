== App name ==
Sepak Takraw Unleashed

== Short description ==
セパタクローをスマホで。ローリングスパイク、ホースキックサーブ、ネット際のブロック。

== Full description ==
Sepak Takraw Unleashed は、東南アジアの「足のバレーボール」セパタクローをスマホで楽しめるゲームです。サークルに片足を置いてサーブし、足の内側でレシーブ、ネット際に高く上げて、ブロックの上からローリングスパイクを叩き込もう。

本物のセパタクロー
• 現行のルール：1セット15点（2点差、最大17点）、3セットマッチ、サーブは1点ごとに交代、タッチは各チーム3回まで。
• レグ、クワッド、ダブルス、チーム戦。男子も女子も、公式寸法のコートとネットで。
• おなじみの技：インサイドキック、インステップでのレシーブ、ヘディング、ホースキックサーブ、ローリングスパイク、サンバック、ソールスパイク、フェイント、ブロック。
• 主審が反則をコールし、線審がイン・アウトを判定。ビデオチャレンジで判定を覆すことも。

遊び方
• クイックマッチ：好きな2チーム、好きな会場で。
• リーグシーズン：マレーシア、タイ、インドネシアの方式で戦うクラブのフルシーズン（クラブは架空）。マレーシア：7つのグランプリ、すべての順位にポイント、昇格と降格。タイ：ホーム＆アウェー、各対戦はレグ2試合。インドネシア：5つの地域を戦い、ジャカルタでの全国決勝へ。
• 国際大会：世界選手権、ロイヤルカップ、アジア選手権、東南アジア選手権。タイ、マレーシア、ベトナム、インドネシア、ミャンマー、日本、韓国などが出場。

5つの会場
ナショナルアリーナ、ショッピングモールのコート、地方体育館、照明に照らされた公園のコート、夕暮れのビーチ。

自分のスタイルで
• 13言語に対応：English、ไทย、Bahasa Melayu、Bahasa Indonesia、Tiếng Việt、ລາວ、မြန်မာ、ខ្មែរ、Filipino、日本語、한국어、中文、हिन्दी。
• オートプレイなし：ジョイスティックで選手をボールまで走らせ、リングがボールに縮んだ瞬間にキック。走りのアシストと試合のスピードは選べます。
• 低価格〜ミドルレンジのスマホでも快適に動くように作られています。
• オフラインでプレイ可能。広告なし、課金なし、アカウント不要、データ収集なし。

Sepak Takraw Unleashed は独立系のゲームです。セパタクローの連盟、リーグ、クラブ、選手とは一切関係がなく、承認も受けていません。クラブの愛称は架空で、選手も架空の人物です。国、場所、ルールは実在のものです。
