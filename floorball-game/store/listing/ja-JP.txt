== App name ==
Floorball Unleashed

== Short description ==
5人+ゴールキーパー、本格ルールのフロアボール。シュート、パス、ゴールを決めよう！

== Full description ==
Floorball Unleashedは、スマホで遊べるフロアボールです。スウェーデン、フィンランド、スイス、チェコで人気の、スピーディーな室内スティック競技。ボードに囲まれた40m×20mのリンクで、5人とゴールキーパー1人ずつが戦います。

本物の試合
• 2026年7月1日施行版のフロアボール国際競技規則に準拠：時計を止める3ピリオド制、フェイスオフ、3mの距離を守るヒットインとフリーヒット、ゴールエリアとゴールキーパーエリア、2分間・5分間の退場、パワープレー、延長戦、ペナルティショット。
• 2026年の新ルールにも対応：フィールドプレーヤーはゴールキーパーエリアを通過不可、ゴールキーパーのスローで得点可能、同時退場で選手がリンクから減らなくなりました。
• 本物と同じように笛を吹き、すべての判定をシグナルで示す2人のレフェリー：フリーヒット、アドバンテージ、ディレイドペナルティ、2分間退場、パッシブプレー、ゴール。
• 試合終盤、リードされたチームはゴールキーパーを下げて6人目のフィールドプレーヤーを投入。反則した選手はペナルティベンチに入り、退場時間を過ごします。
• フロアボールらしく戦うチーム：2-1-2の守備、約50秒ごとのフライングチェンジ、サイドに開くウイング、スロットに構えるセンター。

遊び方いろいろ
• クイックマッチ：男女22の代表チームが、市民アリーナ、スポーツホール、学校の体育館で対戦。ピリオドの長さは4〜20分、実時間制かランニングタイムを選べます。
• 世界決勝大会：16か国が4グループに分かれ、プレーオフ、準々決勝、準決勝、メダルマッチへ。
• クラブシーズン：10クラブによる勝点3-2-1-0のリーグ戦（60分での勝ちが3、延長戦またはペナルティショットでの勝ちが2、延長戦での負けが1）のあと、準決勝と決勝。
• 試合ごとのボックススコア：枠内シュート、セーブ、ペナルティ時間、パワープレーゴール、すべての得点と罰則を該当する規則とともに表示。

自分好みのプレーを
• 15言語に対応：English、Svenska、Suomi、Deutsch、Français、Italiano、Čeština、Slovenčina、Norsk、Dansk、Latviešu、Eesti、Polski、日本語、ไทย。
• 最初の試合はコーチがガイドします。ジョイスティックと3つのボタン。左利き配置、3段階のサイズ、親指の好きな位置への移動に対応。
• 低価格帯・ミドルレンジのスマホでもなめらかに動作。省電力モード付き。
• オフラインでプレー可能。広告なし、課金なし、アカウント不要、データ収集なし。

Floorball Unleashedは独立系のゲームです。いかなるフロアボールの連盟、リーグ、クラブ、選手とも提携しておらず、推奨も受けていません。選手は架空ですが、国とルールは本物です。
