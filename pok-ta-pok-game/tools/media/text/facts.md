# Fact sheet

| | |
|---|---|
| **Game** | Pok Ta Pok Rivals |
| **Sport** | The Mesoamerican ballgame: ulama de cadera (hip ulama, Sinaloa, Mexico) and a reconstruction of the classic stone court |
| **Players a side** | Ulama: 4 or 5 (default 5). Classic court: 2, 3 or 4 (default 3) |
| **Game modes** | Play a match; Town tournament (eight towns, knock-out); Watch a match (computer against computer). You control the whole team or one player |
| **Opponents** | Three levels: Village, Regional, Champion |
| **Courts** | Four: a village court in Sinaloa at dusk, a festival court by day, a stone court in the Yucatán forest, the stone court by torchlight |
| **Towns** | Sixteen, from Mexico (Sinaloa, Yucatán, Quintana Roo, Chiapas), Guatemala, Belize and Honduras |
| **Languages** | Spanish, English, Portuguese (Brazil), French, German, Italian |
| **Graphics levels** | Low, Medium, High (set for the phone on first run; can step down by itself if a match runs slowly) |
| **Offline** | Yes, fully. The game does not use the internet |
| **Permissions** | One: vibration (can be turned off in Settings) |
| **Ads / purchases / data** | None / none / no data collected |
| **Platform** | Android, phones and tablets, landscape |
| **Minimum Android** | Android 7.0 (API 24) |
| **Download size** | Beta APK about 122 MB. From Google Play, about 95 MB for one phone |
| **Current version** | 0.5.4-beta |
| **Engine** | Godot Engine 4 |
| **Developer** | Josh Nason |
| **Contact** | joshnason8@gmail.com |
