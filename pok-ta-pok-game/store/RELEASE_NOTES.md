# First Google Play release: release notes

Paste each into Play Console > the release > Release notes, between the language tags Play shows.
Play's limit is 500 characters per language.

<en-US>
The first release on Google Play. Ulama de cadera from Sinaloa and the stone courts of the Yucatán: four courts, sixteen towns and a town tournament, in six languages. Lifelike players, the serve off the bounce on the stone courts, the copal offering before games there, and a replay for a ball through the ring. No ads, no purchases, no data collected.
</en-US>
