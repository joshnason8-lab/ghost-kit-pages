# Hindi / Marathi / Nepali: terms for a native speaker to check

## Hindi (hi)
- Chaser / defender: used the loanwords चेज़र / डिफ़ेंडर (as on Hindi TV commentary), and "सक्रिय चेज़र" for the active chaser. Some people may prefer "एक्टिव चेज़र".
- Turn = "टर्न", innings = "पारी", batch = "बैच", squares = "खाने", central lane = "बीच की लेन", cross lane = "क्रॉस लेन", free zone = "फ़्री ज़ोन".
- Pole = "खंभा" in normal text, but "पोल डाइव" for the move.
- TURN_SHORT is still "T{n}" (Latin letter). Is there a short Hindi form people would accept?
- COL_P/W/D/L = मै/जी/टा/हा (मैच/जीत/टाई/हार). Please check these are readable as table headers.
- BTN_DODGE = "चकमा", BTN_SWITCH = "बदलें".
- Toss heads/tails = चित/पट.
- X_CHASES = "{team} का पीछा" (meaning "{team} is chasing"). It may read better as "{team} पीछा कर रही है".

## Marathi (mr)
- Used the usual Marathi kho-kho words: आक्रमक (chaser), संरक्षक (defender), आक्रमण/संरक्षण (chasing/defending), डाव (innings), तुकडी (batch), खांब (pole), चौकोन (square), मधली पट्टी / आडवी पट्टी (central/cross lane), मुक्त क्षेत्र (free zone), गुण (points), बाद (out in text; the shout is "आउट!").
- Turn = "पाळी", and TURN_SHORT = "पा{n}". Please check this is what players say.
- Dive: used "डाइव" (button and moves "स्काय डाइव", "पोल डाइव"). "सूर" is used once in CTRL_DIVE_TEXT. Should the button be "सूर"?
- BTN_DODGE = "हुलकावणी" is a little long for a round button. Is there a shorter word?
- COL_P/W/D/L = सा/वि/ब/प (सामने/विजय/बरोबरी/पराभव).
- FORMAT_CLASSIC = "पारंपरिक", FORMAT_FAST = "वेगवान". These may be better as the loanwords क्लासिक/फास्ट.
- Lane assist = "पट्टी सहाय्य".
- Wazir is spelled "वझीर" (Marathi spelling). It could also be वजीर.
- QF/SF = उपउपांत्य/उपांत्य.

## Nepali (ne)
- Chaser/defender = चेजर/डिफेन्डर, chase = पछ्याउनु, defend = रक्षा गर्नु, team = टोली, turn = पालो, innings = इनिङ्स, batch = ब्याच, pole = खम्बा (and "पोल डाइभ" for the move), squares = कोठा.
- Dive is spelled डाइभ (the usual Nepali transliteration), dream run is ड्रिम रन, and wazir is वजिर.
- Toss heads/tails = हेड/टेल. Should these be "चित/पट" or something else?
- TURN_SHORT is still "T{n}".
- COL_P/W/D/L = खे/जि/ब/हा (खेल/जित/बराबरी/हार).
- ON/OFF = खुला/बन्द. "अन/अफ" may be more common in app settings.
- BTN_DODGE = "छल", BTN_SWITCH = "बदल".
- State spellings: केरला, पञ्जाब, छत्तीसगढ, आसाम.
