# Tamil / Malayalam: terms for a native speaker to check

## Tamil (ta)
- Chaser = "துரத்துபவர்", active chaser = "ஓடும் துரத்துபவர்", seated chaser = "அமர்ந்த துரத்துபவர்". Defender = "தடுப்பாளர்"; chasing/defending = "துரத்தல்"/"தடுப்பு". Do Tamil players say "ஓட்டக்காரர்" (runner) for defenders, or the loanwords சேசர்/டிஃபெண்டர்?
- Pole = "கம்பம்", and the move is "கம்ப டைவ்". Commentary may say "போல் டைவ்" instead.
- Loanwords: டைவ், அவுட், ஃபவுல், வசீர், ட்ரீம் ரன், பவர் ப்ளே, ஃபாலோ-ஆன், இன்னிங்ஸ், டர்ன், பேட்ச் (batch), ஃப்ரீ சோன். Is "முறை" better than "டர்ன்"?
- Square = "கட்டம்", central lane = "மையப் பாதை", cross lane = "குறுக்குப் பாதை".
- TURN_SHORT = "ட{n}". Is this readable, or should it stay "T{n}"?
- Buttons: BTN_POWERPLAY = "பவர்ப்ளே" (written as one word to fit), BTN_DODGE = "விலகு", BTN_SWITCH = "மாற்று".
- Table headers: COL_P/W/D/L = ஆ/வெ/ச/தோ (ஆடியது/வெற்றி/சமன்/தோல்வி), COL_PTS = "புள்", COL_BEST = "உச்சம்" (best run). Please check these read clearly.
- Toss: heads/tails = "தலை"/"பூ".
- PLAYER_OF_MATCH = "ஆட்ட நாயகர்" (the respectful form, so it also works for women's matches).
- Short buttons use the informal imperative (ஆடு, தொடர், தடு). Check this tone is fine compared with the polite -ங்கள் form.
- FORMAT_FAST = "வேகம்", FORMAT_CLASSIC = "கிளாசிக்" (a mix of a native word and a loanword).

## Malayalam (ml)
- Used the loanwords that are common in Malayalam sports reporting: ചേസർ, ആക്ടീവ് ചേസർ, ഡിഫൻഡർ, ചേസ്/ചേസിങ്, ഡിഫൻസ്, ഡൈവ്, ഔട്ട്, ഫൗൾ, വസീർ, ഡ്രീം റൺ, പവർ പ്ലേ, ഫോളോ-ഓൺ, ഇന്നിങ്സ്, ടേൺ, ബാച്ച്, ലെയ്ൻ, ഫ്രീ സോൺ. Would native words such as പിന്തുടരുന്നവർ/പ്രതിരോധം be better anywhere?
- Pole = "തൂൺ" in normal text, but the move is "പോൾ ഡൈവ്". Some people may say "കമ്പം".
- Square = "കളം", central lane = "മധ്യ ലെയ്ൻ", cross lane = "ക്രോസ് ലെയ്ൻ".
- TAGLINE = "ഇരിക്കൂ. ഖോ. ചേസ്!". Please check it sounds natural.
- TURN_SHORT = "ടേ{n}". Is this readable, or should it stay "T{n}"?
- Buttons: BTN_DODGE = "വെട്ടിക്ക്" (colloquial for dodging), BTN_SWITCH = "മാറ്റൂ", BTN_POWERPLAY = "പവർപ്ലേ" (written as one word to fit).
- Table headers: COL_P/W/D/L = ക/ജ/സ/തോ (കളി/ജയം/സമനില/തോൽവി), COL_PTS = "പോ.", COL_PLAYER = "താരം", COL_BEST = "ബെസ്റ്റ്".
- Toss: heads/tails = "ഹെഡ്‌സ്"/"ടെയിൽസ്" (loanwords). Is there a local pair people use?
- VS left as "vs". Malayalam often writes "vs", but "എതിരെ" is possible.
- MENU_SETTINGS = "ക്രമീകരണം" (singular, kept short), CAM_TV = "ടിവി", CALL_LATE_ENTRY = "വൈകിയ എൻട്രി".
- MOVE_WAZIR_TEXT uses "കുഴപ്പക്കാരനായ ഡിഫൻഡർ" for "trickiest defender". Please check the tone.
