# Translator notes: gu / pa / si

Terms a native speaker (ideally a kho kho player or coach) should check.

## Gujarati (gu)

- Chaser / defender: I used the loanwords ચેઝર / ડિફેન્ડર, and સક્રિય ચેઝર for "active chaser". Check whether local coaches say something else, such as પીછો કરનાર / દોડનાર.
- Chase = પીછો, defend = બચાવ, innings = દાવ, turn = ટર્ન, batch = ટુકડી.
- Lanes: central lane = મધ્ય લેન, cross lane = આડી લેન, square = ખાનું, free zone = ફ્રી ઝોન.
- Pole dive = "થાંભલા ડાઇવ" is my own wording. "પોલ ડાઇવ" may be what players actually say.
- BTN_DODGE = છટકો ("slip away"). Check that it reads well as a one-word button.
- Table abbreviations: COL_P મે, COL_W જી, COL_D ટા (tie), COL_L હા, COL_PTS પો. These are invented short forms.
- TURN_SHORT = ટ{n}. Players might prefer the Latin "T{n}".
- Heads / tails = છાપ / કાંટો.
- C_USA = અમેરિકા (the everyday name, not the formal યુનાઇટેડ સ્ટેટ્સ).

## Punjabi, Gurmukhi (pa)

- Chaser / defender: loanwords ਚੇਜ਼ਰ / ਡਿਫੈਂਡਰ, with ਸਰਗਰਮ ਚੇਜ਼ਰ for "active chaser".
- Turn = ਵਾਰੀ, innings = ਪਾਰੀ, batch = ਟੋਲੀ, chase = ਪਿੱਛਾ, defend = ਬਚਾਅ.
- Pole = ਖੰਭਾ, so pole dive = "ਖੰਭਾ ਡਾਈਵ". This is my own wording; check it.
- BTN_DODGE = ਝਕਾਨੀ, borrowed from kabaddi. Check that it fits kho kho.
- Heads / tails are given as the loanwords ਹੈੱਡ / ਟੇਲ.
- Table abbreviations: COL_P ਮੈ, COL_W ਜਿ, COL_D ਬ (ਬਰਾਬਰ), COL_L ਹਾ. TURN_SHORT = ਵ{n}. These are invented short forms.
- "Minimum chase" = ਘੱਟੋ-ਘੱਟ ਪਿੱਛਾ. RESULT_MIN_CHASE ("ਘੱਟੋ-ਘੱਟ ਪਿੱਛਾ ਰਾਹੀਂ") needs a fluency check.
- C_USA = ਅਮਰੀਕਾ.

## Sinhala (si)

- Kho is written කෝ (not ඛෝ). Please confirm which form Sri Lankan players use.
- Chaser = ලුහුබඳින්නා, chase = ලුහුබැඳීම, defender = ආරක්ෂකයා. The tagline uses පන්නන්න ("chase off"). Check whether players just say "චේසර්".
- Out = අවුට් (loanword). Foul = ෆවුල්. Dive = ඩයිව්. Pole dive = කණු ඩයිව්.
- Batch = බැච් (loanword). කාණ්ඩය is used for tournament groups, so I did not use it for batches.
- Wazir = වසීර්. Dream run = ඩ්‍රීම් රන්. Power play = පවර් ප්ලේ. Follow-on = ෆලෝ-ඔන්.
- Innings = ඉනිම, the cricket term. Turn = වාරය.
- Heads / tails = හෙඩ්ස් / ටේල්ස් (loanwords). A native term may be better.
- ON / OFF = සක්‍රිය / අක්‍රිය. BTN_DODGE = මගහරින්න is long for a round button; BTN_SWITCH = මාරු.
- Player of the match = තරගයේ වීරයා (the usual cricket phrase).
- Table headers: තරග / ජය / සම / පරා / ලකුණු. These are longer than 1–4 letters, so check whether they fit.
- Spelling of the Indian state names (e.g. ආන්ද්‍ර ප්‍රදේශ්, ඡත්තීස්ගඩ්, හර්යානා) varies in Sri Lankan media.
- Conjuncts use ZWJ (e.g. ක්‍රී, ප්‍ර). Please check how they render on target fonts.
