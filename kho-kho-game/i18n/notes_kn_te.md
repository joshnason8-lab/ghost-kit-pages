# Kannada / Telugu: terms for a native speaker to check

## Kannada (kn)
- Chase/defend are written with native verbs: ಬೆನ್ನಟ್ಟು (chase), ರಕ್ಷಿಸು/ರಕ್ಷಣೆ (defend). The player nouns are loanwords: ಚೇಸರ್, ಆಕ್ಟಿವ್ ಚೇಸರ್, ಕುಳಿತ ಚೇಸರ್, ಡಿಫೆಂಡರ್. Is this mix natural, or do players say ಓಟಗಾರ (runner) for defenders, or the native word for "chaser"?
- MIN_CHASE = "ಕನಿಷ್ಠ ಚೇಸ್" (noun, loanword), next to the native verb ಬೆನ್ನಟ್ಟು.
- Pole = "ಕಂಬ", and the move is "ಕಂಬ ಡೈವ್". Commentary may say "ಪೋಲ್ ಡೈವ್" instead.
- Turn = "ಸರದಿ" (native). TURN_SHORT = "ಸ{n}". Is it readable, or should it stay "T{n}"?
- Field = "ಅಂಕಣ", square = "ಚೌಕ", central/cross lane = "ಮಧ್ಯ ಲೇನ್"/"ಅಡ್ಡ ಲೇನ್", free zone = "ಫ್ರೀ ಜೋನ್".
- Points = "ಅಂಕ". A level score = "ಸಮಬಲ" (in CALL_EXTRA_INNINGS and CALL_MIN_CHASE).
- Toss: "ಹೆಡ್ಸ್"/"ಟೇಲ್ಸ್" (loanwords). Is there a local pair people use?
- Buttons: BTN_DODGE = "ಡಾಡ್ಜ್" (loanword, kept short), BTN_SWITCH = "ಬದಲು", BTN_POWERPLAY = "ಪವರ್‌ಪ್ಲೇ" (one word so it fits).
- Table headers: COL_P/W/D/L = ಆ/ಗೆ/ಟೈ/ಸೋ (ಆಡಿದ/ಗೆಲುವು/ಟೈ/ಸೋಲು), COL_PTS = "ಅಂಕ", COL_BEST = "ಶ್ರೇಷ್ಠ" (best run). Please check these read clearly.
- VS left as "vs" ("ವಿರುದ್ಧ" is possible but longer).
- FOLLOW_ON_Q = "ಫಾಲೋ-ಆನ್ ಹೇರುವಿರಾ?" ("impose the follow-on"). Check that it sounds natural.
- PLAYER_OF_MATCH = "ಪಂದ್ಯಶ್ರೇಷ್ಠ". C_USA = "ಅಮೆರಿಕ" (short form).

## Telugu (te)
- Mostly the loanwords heard in Telugu sports commentary: ఛేజ్/ఛేజింగ్, ఛేజర్, యాక్టివ్ ఛేజర్, కూర్చున్న ఛేజర్, డిఫెండర్, డిఫెన్స్. The native verb వెంటాడు appears only in the TAGLINE. Would వెంటాడటం/రక్షణ be better anywhere?
- The spelling is "ఛేజ్" (as in cricket). Some writers use "చేజ్".
- Pole = "స్తంభం", and the move is "స్తంభం డైవ్". Commentary may say "పోల్ డైవ్" instead.
- Turn = "టర్న్" (loanword). "వంతు" is an option. TURN_SHORT = "ట{n}". Is it readable, or should it stay "T{n}"?
- Field = "కోర్టు", ground = "మైదానం", square = "గడి", central/cross lane = "మధ్య లేన్"/"అడ్డ లేన్".
- Toss: heads/tails = "బొమ్మ"/"బొరుసు".
- Whistle = "విజిల్" (loanword). "ఈల" is the native word.
- Buttons: BTN_DODGE = "డాడ్జ్", BTN_SWITCH = "మార్చు", BTN_POWERPLAY = "పవర్‌ప్లే" (one word so it fits).
- Table headers: COL_P/W/D/L = ఆ/గె/టై/ఓ (ఆడినవి/గెలుపు/టై/ఓటమి), COL_PTS = "పా" (పాయింట్లు). Least sure about "పా" and "ఓ".
- FOLLOW_ON_Q = "ఫాలో-ఆన్ ఆడిస్తారా?". Check that it sounds natural.
- PLAYER_OF_MATCH = "ప్లేయర్ ఆఫ్ ద మ్యాచ్" (as in TV). "మ్యాచ్ హీరో" is shorter if space is tight.
- C_IND = "భారత్" (not "భారతదేశం"), C_USA = "అమెరికా". VS left as "vs".
