# Fact sheet

| | |
|---|---|
| Game | Kho Kho Rush |
| Sport | Kho kho, the traditional chasing (tag) game of India |
| Players per side | 9 on the field in the classic game (8 seated in the lane, 1 chasing; 3 defenders on at a time); 7 in the fast game |
| Game modes | Quick Match; Championships: world (16 nations), national (16 states), city league (8 city sides), men's and women's; Watch a Match |
| Rules | Classic and fast |
| Grounds | Village ground (dusk), school ground (morning), indoor arena (mats), floodlit stadium (night) |
| Languages | English, Hindi, Marathi, Kannada, Telugu, Tamil, Malayalam, Odia, Bengali, Gujarati, Punjabi, Assamese, Nepali, Sinhala |
| Graphics levels | Low, Medium, High (chosen for the phone; lowered automatically if a match runs slowly) |
| Plays offline | Yes. No internet permission |
| Permissions | Vibration only |
| Data collected | None. No account, ads, analytics or purchases |
| Platform | Android |
| Minimum Android | Android 7.0 (API 24) |
