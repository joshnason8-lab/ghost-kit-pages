== App name ==
Kho Kho Rush: ખો-ખો

== Short description ==
સાચા નિયમો સાથે ખો-ખો: લેનમાં બેસો, ખો આપો, પીછો કરો અને થાંભલા ડાઇવ મારો.

== Full description ==
Kho Kho Rush એટલે તમારા ફોનમાં ખો-ખો: ભારતની પીછો કરવાની રમત. તમારી ટીમ સાથે લેનમાં બેસો, ખો મળતાં જ ઊભા થાઓ, ડિફેન્ડરોનો થાંભલા સુધી પીછો કરો, અને ટર્ન પૂરો થાય તે પહેલાં ડાઇવ મારીને અડો અને આઉટ કરો.

સાચી રમત
• બે નિયમપોથી. ક્લાસિક, જેમ રાષ્ટ્રીય ચૅમ્પિયનશિપમાં રમાય છે: દરેક ટીમમાં નવ ખેલાડી, આઠ ખાનાઓમાં બેઠેલા, 27 મી.નું મેદાન, દરેક આઉટનો 1 પોઇન્ટ, અને ફૉલો-ઑન. ફાસ્ટ, જેમ 2025ની વિશ્વ ચૅમ્પિયનશિપમાં રમાઈ: દરેક ટીમમાં સાત ખેલાડી, 22 મી.નું મેદાન, દરેક આઉટના 2 પોઇન્ટ, ડ્રીમ રન, વઝીર અને પાવર પ્લે.
• સક્રિય ચેઝરનો દરેક નિયમ: દિશા પકડો અને તેને વળગી રહો, મધ્ય લેન ક્યારેય ઓળંગશો નહીં, વળો તો માત્ર થાંભલાની ફરતે, અને આડી લેન પસાર કરો તે પહેલાં પાછળથી ખો આપો.
• ડિફેન્ડરો ત્રણ-ત્રણની ટુકડીમાં મેદાનમાં આવે છે. આઉટ થાય અડવાથી, સ્કાય ડાઇવથી, થાંભલા ડાઇવથી, રેખા બહાર પગ મૂકવાથી કે મોડા પ્રવેશથી.
• બંને બાજુની રેખા પર અમ્પાયર, જે ફાઉલ સુધરે નહીં ત્યાં સુધી સીટી વગાડતા રહે, સાથે રેફરી અને સમયપાલક. નૉકઆઉટમાં ટાઈ થાય તો વધારાનો દાવ અને ન્યૂનતમ પીછો ફેંસલો કરે છે.

રમવાની રીતો
• ઝડપી મૅચ: કોઈ પણ બે ટીમ, કોઈ પણ મેદાન, કોઈ પણ નિયમપોથી. ટૉસ તમે બોલો, પછી પીછો કરવો કે બચાવ કરવો તે પસંદ કરો.
• ચૅમ્પિયનશિપ: વિશ્વ ચૅમ્પિયનશિપમાં સોળ દેશો, અથવા રાષ્ટ્રીય ચૅમ્પિયનશિપમાં સોળ રાજ્યો: ગ્રૂપ સ્ટેજ, ક્વાર્ટર-ફાઇનલ, સેમિ-ફાઇનલ, ફાઇનલ. પુરુષો અને મહિલાઓ બંને માટે.
• સિટી લીગ: આઠ કાલ્પનિક શહેરની ટીમો ફાસ્ટ નિયમોથી એકબીજા સામે ઘરઆંગણે અને બહાર રમે છે, પછી ટોચની ચાર ટીમો સેમિ-ફાઇનલમાં પહોંચે છે.
• મૅચ જુઓ: બે ટીમો જાતે જ આખી મૅચ રમે છે.

ચાર મેદાન
સાંજના અજવાળે ટીપેલી માટીનું ગામનું મેદાન, સવારનું શાળાનું મેદાન, મૅટ પાથરેલું ઇન્ડોર એરિના, અને ફ્લડલાઇટમાં ઝળહળતું લાલ માટીનું સ્ટેડિયમ.

તમારી રીતે રમો
• ચૌદ ભાષાઓ: English, हिन्दी, मराठी, ಕನ್ನಡ, తెలుగు, தமிழ், മലയാളം, ଓଡ଼ିଆ, বাংলা, ગુજરાતી, ਪੰਜਾਬੀ, অসমীয়া, नेपाली અને සිංහල.
• કોચની ટિપ્સ તમારી પહેલી મૅચમાં પીછો કરવામાં અને બચાવ કરવામાં, બંનેમાં તમને ડગલે ને પગલે માર્ગદર્શન આપે છે.
• સરળ ટચ કંટ્રોલ: તમારા ચેઝર માટે જૉયસ્ટિક, ખો અને ડાઇવ. બટનોને અંગૂઠો સહેલાઈથી પહોંચે ત્યાં ખસેડો, મોટાં કરો, અથવા ડાબા હાથે રમો.
• ઝડપી રમત માટે 3 કે 5 મિનિટના ટર્ન, અથવા પૂરી સાચી લંબાઈની મૅચ.
• સસ્તા અને મધ્યમ કિંમતના ફોન પર પણ સરળતાથી ચાલે તે રીતે બનાવેલી.
• ઑફલાઇન રમો. કોઈ જાહેરાત નહીં, કોઈ ખરીદી નહીં, કોઈ એકાઉન્ટ નહીં, અને કોઈ ડેટા એકત્ર થતો નથી.

Kho Kho Rush એક સ્વતંત્ર રમત છે. તે કોઈ પણ ખો-ખો ફેડરેશન, લીગ, ક્લબ કે ખેલાડી સાથે સંકળાયેલી નથી કે તેમના દ્વારા સમર્થિત નથી. ખેલાડીઓ કાલ્પનિક છે; દેશો, રાજ્યો અને નિયમો વાસ્તવિક છે.

== Release notes (0.9.2) ==
બહારનાં મેદાનો હવે ટુર્નામેન્ટના શણગારમાં, સાચી મેચોની જેમ: સ્ટીલના બેરિકેડ, ટીમો પર તંબુ, ધ્વજ અને બેનર, ગામના મેદાને મંચ, અને રોજનાં કપડાંમાં ભીડ. સાચી મેચોમાંથી શીખેલા બચાવકર્તા: જોખમની બહાર તેઓ ઊભા રહીને પીછો જુએ છે. અધિકારીઓની જગ્યાએથી સાચી રેફરી સીટીઓ. મધ્યમ અને ઊંચા ગ્રાફિક્સ પર વધુ સ્પષ્ટ જમીન, ખેલાડીઓ અને આકાશ. ભીડ અને મેદાનના અવાજો હવે લાંબા.
