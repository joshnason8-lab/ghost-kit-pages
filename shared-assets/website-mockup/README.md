# Studio website mockup

The owner approved this design on 27 Oct 2026 as the basis for the studio's WordPress site.

- `home.html`: the home page, with every game card, region filters, "why our games feel different", a Play banner and the footer.
- `game.html`: a per-game page (Hurling Heroes example), with the trailer, thumbnails, facts table, features and "About the sport".
- `mockup-*.png`: rendered screenshots at 1440 px.
- `img/`: each game's 512 px icon and its 1024×500 feature graphic, copied from each game branch's `assets/icon/icon_512.png` and `store/graphics/feature-1024x500.png`.

These are placeholders:
- the studio name "Ghost Kit Games";
- "20+ languages";
- the "TBC" facts;
- the thumbnail images.

Real screenshots, trailers and text come from each game's media kit (release tag `<slug>-media`).
