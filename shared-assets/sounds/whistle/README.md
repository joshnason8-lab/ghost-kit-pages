# Referee whistle (real recordings)

Real pea-whistle blasts, supplied by the owner from Pixabay. Each clip is trimmed and faded, mono 44.1 kHz,
loudness-matched (about -16 LUFS, peaks under -6 dBFS) and saved as Ogg Vorbis q4. Every game was missing a recorded whistle.

| File | Length | Use |
|---|---|---|
| whistle_short_a / _b / _c.ogg | 0.5-0.7 s | short pip: a foul or a restart. Pick one at random |
| whistle_long_a / _b / _c.ogg | 1.0-1.2 s | long blast: start of play, a goal or point, end of a period |
| whistle_double.ogg | 1.0 s | two quick pips: a stoppage, a time-out, a substitution |
| whistle_final.ogg | 2.6 s | short, short, long: the final whistle |
| whistle_gym.ogg | 1.6 s | a long blast recorded in a gym, with the hall's echo: use it in indoor halls |

Play them from the referee's position (3D) where the game has one. Don't play them in the home-screen background match,
or at most quietly.
